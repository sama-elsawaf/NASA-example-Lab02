# NASA-example-Lab02

## Project idea: 
The project idea is to create an application that aids NASA by having a live tracking of endangered marine animals around the world. This helps NASA by centralizing all the data into an application that is easily accessible and helps in creating a secure area to track said animals. 


## Technologies/tools used 
1. Live GPS tracking
2. Live updates about specified marine life
3. Tracking and storing usual/commonly visited places by the marine life

## How to run
1. Download the .exe file
2. Input all requried login credentials
3. Enjoy!
