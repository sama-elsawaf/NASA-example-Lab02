# Reflection:
What was fun: 
1. Into a visual
2. Collaborative game board where you can assign tasks
3. Drag cards across digital Kanban boards,
4. Watch a project come to life.

Within the repository itself, Collaborative Pull Requests let you leave emojis or reviews on a teammate's line of code, 
while GitHub Actions can automatically run a digital checklist or post a celebration gif every time someone successfully deploys new features.

The biggest challenge is: shifting your mindset to dealing with branches (staging then committing) and dealing with a merge conflict, which happens when Git gets confused by conflicting changes on the same line and forces you to manually decide which code to keep.

What I will work on more if I had time, is the Team project board, as I believe I didn't use the description feature to its potential.
